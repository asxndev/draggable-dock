# draggable-dock


1. Open Android Studio.
2. Navigate to Tools > SDK Manager (or Settings > Languages & Frameworks > Android SDK).
3. Select the SDK Tools tab.
4. Check the Show Package Details box in the bottom-right corner.
5. Expand Android SDK Command-line Tools.
6. Uncheck the newer version (v23.0+) and check version 22.0.
7. Click Apply to install the older version.
